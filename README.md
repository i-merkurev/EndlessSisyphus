# Бесконечный Сизиф / Endless Sisyphus

Основная браузерная версия 2D-игры по мотивам мифа о Сизифе и философии абсурда Альбера Камю.

Игрок толкает камень вверх по бесконечному склону, приспосабливаясь к ветру, дождю, льду и увеличению крутизны. Цель попытки: подняться как можно выше, пока не иссякнут силы. Победного финала нет.

## Технологии
JavaScript, Canvas 2D, CSS и Web Audio API. Для игры не требуются backend и JavaScript-сборщик.

## Управление
| Препятствие | Действие |
|---|---|
| Обычный склон | Ритмично нажимать Space |
| Лёд | Удерживать Space |
| Крутой склон | Shift + Space |
| Дождь | C + Space (режим осторожного движения) |
| Ветер | Отпустить клавиши |
| Главное меню | Esc |
| Новая попытка | R |

## Локальный запуск
```bash
python3 -m http.server 8000 --directory public
```
Открой http://localhost:8000 в браузере.

## Публикация
Действующий сайт: https://endless-sisyphus-game.netlify.app/

Репозиторий содержит отдельный конфиг `netlify.toml` для публикации папки `public`. Подключение Netlify к GitHub выполняется отдельно после проверки источников и сборки.
